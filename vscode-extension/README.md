# Devo - AI Coding Agent

**一个会自己写代码、自己跑、报错了自己修、修不好再来、直到搞定的 AI 编码助手。**

你说话，它干活。你只需要在它要动手的时候点个头。

---

## 它能做什么

Devo 是一个**对话驱动的自主编码智能体**，不是简单的代码补全工具。你给它一个需求，它自己分析、写代码、跑命令、看报错、修 Bug，循环迭代直到搞定。

### 核心能力

| 能力 | 说明 |
|------|------|
| 自主编码 | 根据自然语言需求，自己写代码、改代码、创建文件 |
| 自动调试 | 代码写完自己跑，报错了自己分析原因、自己修复 |
| 命令执行 | 编译、运行、安装依赖，所有操作在你的项目目录内完成 |
| 代码搜索 | 读文件、搜索代码库，理解你的项目现状 |
| 迭代修复 | 一次修不好就再来，反复直到跑通 |

### 安全与审批

| 机制 | 说明 |
|------|------|
| 风险分级 | 操作分高/中/低三级，命令执行默认高风险，文件操作中风险，记忆更新低风险 |
| 审批弹窗 | 高风险操作必须你点头才执行，附带你改了什么的 diff |
| 信任策略 | 熟悉后可以设"本次会话自动批准"，甚至"永久信任" |
| 审批超时 | 超时不回复自动拒绝，不卡死 |
| 路径安全 | 所有文件操作强制限定在工作目录内，无法越界 |
| 命令过滤 | 自动拦截 `rm -rf /`、`format C:` 等恶意命令 |

### 会话管理

| 功能 | 说明 |
|------|------|
| 会话隔离 | 每个会话绑定一个项目目录，互不干扰 |
| 暂停/恢复 | 随时暂停，下次打开接着聊，聊天记录全在 |
| 消息回滚 | 聊到一半不满意，回滚到任意消息，从头再来 |
| 会话归档 | 完成后归档，记录保留，不再修改 |
| 崩溃恢复 | 服务异常重启后自动恢复，不会卡死 |

### 智能特性

| 特性 | 说明 |
|------|------|
| 上下文压缩 | 长对话自动压缩，不会超出 LLM 窗口限制 |
| 长期记忆 | 它会记住你的偏好和项目习惯，越用越懂你 |
| 技能固化 | 完成一个会话后，自动提炼经验，沉淀为可复用的技能 |
| agents.md | 项目根目录放一个 `agents.md`，就是你的项目级编码规范 |
| 会话存档 | 每个会话自动生成 Markdown 存档，可查看、分享、Git 提交 |
| Token 计量 | 实时统计每次对话的 Token 消耗，成本透明 |

### 实时反馈

整个过程中，AI 在干什么你都能实时看到：
- 开始思考、调用什么工具、执行结果
- 修复了第几次、报了什么错
- 需要你审批什么操作
- 每次 LLM 调用消耗了多少 Token

## 如何打开

安装扩展后，有三种方式打开 Devo：

| 方式 | 位置 |
|------|------|
| 编辑器工具栏 | 编辑器右上角的 $(hubot) 图标 |
| 状态栏 | 右下角的 `$(hubot) Devo` 按钮 |
| 命令面板 | `Ctrl+Shift+P` → 输入 `Open Devo` |

---

## 典型工作流

1. 打开 Devo，创建会话，指定你的项目目录
2. 说需求：**"帮我写一个下载网页图片的脚本"**
3. AI 开始分析，可能先搜索项目里有什么，然后生成代码
4. 弹窗让你审代码，你批准，它写入文件
5. AI 自己跑脚本，报错了，它分析错误，再改，再跑
6. 反复几次，跑通了，告诉你搞定
7. 不满意中间某步？回滚聊天记录，用 Git 回退代码，重新来

## 安装

### 从 VSIX 安装

1. 下载最新的 `.vsix` 文件
2. VS Code 中打开 **Extensions**（`Ctrl+Shift+X`）
3. 点击右上角 `...` → **Install from VSIX...**
4. 选择 `.vsix` 文件，安装完成

### 从源码构建

```bash
cd vscode-extension
npm install
npm run compile
npm run vsix
```

---

## 调试

查看扩展日志：

1. 打开 **Output** 面板（`View` → `Output` 或 `Ctrl+Shift+U`）
2. 右侧下拉选择 **Devo**
3. 能看到进程启动、端口分配、stdout/stderr、错误等所有信息

---

## 开发

```bash
npm install          # 安装依赖
npm run compile      # 编译（生产模式）
npm run dev          # 监听模式（开发用）
npm run vsix         # 打包 .vsix
```

## 版本管理

```bash
npm version patch    # 1.0.0 → 1.0.1（Bug 修复）
npm version minor    # 1.0.0 → 1.1.0（新功能）
npm version major    # 1.0.0 → 2.0.0（不兼容大改）
```

## 架构

Devo 采用三层架构，通过 HTTP REST + SSE 实现实时通信：

```
┌─────────────────────────────────────┐
│               UI 层                  │
│  CLI / Web / IDE 插件（本扩展）       │
└────────────┬────────────────────────┘
             │ HTTP (REST) + SSE
┌────────────▼────────────────────────┐
│            接口层 (API)              │
│  REST API · SSE 事件流 · 审批桥接    │
└────────────┬────────────────────────┘
┌────────────▼────────────────────────┐
│         任务处理层 (Task)            │
│  工具集 · Python 沙箱执行器 · LLM    │
└────────────┬────────────────────────┘
┌────────────▼────────────────────────┐
│           核心层 (Core)              │
│  代理循环 · 审批门控 · 上下文压缩     │
│  长期记忆 · 技能管理 · 会话存档      │
└─────────────────────────────────────┘
```
